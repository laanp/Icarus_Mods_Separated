laanp-AdjustableTram_v1_w259_P.pak
----------------------------------------------------------------------
Mod Version: 1

Compatible with Icarus Version: Rev. 3.0.37.160033 (Week: 259)

## Description:
- Programmable Tram floorplate that once deployed, can be programmed to transport a player in any direction.  Can be used as an elevator or slider in any direction that you specify via menu.
 
## Mod Details:

- Creates new deployable object called "Pete's Adjustable Tram", craftable for free in the character crafting menu.
- Compatible with: Single Player, Hosted Multiplayer or Dedicated Server
- Snaps to any floor piece, or free-placement anywhere, and can be used as a simple elevator, or slider.
- When initially deploying, an arrow will show the tram's forward direction, which is also indicated by a small black arrow on the tram floor.
- After deploying the tram, interact with the tram to bring up the tram configuration menu.
- Set the direction, how many floors to travel, and at what speed (2 = default, 5 = quick, 30 = insane), and click the "Save" button to store into tram memory.
- Each deployed Tram retains it's own movement memory, and is saved across sessions (stored with the saved prospect).
- After the tram is programmed, any player can step on it and travel with the tram to the destination.
- A tram can also be called remotely by stepping near the destination location, and the tram will travel to the player.
- Tram is equipped with optional light, that can be toggled as part of the stored tram parameters.
- Locking the player to the tram, will allow travelling through objects! (only for the first player on the tram).
- Press the `T` key while in transit, to return the tram to the location the player first stepped on the tram.
- Tram parameters menu cannot be invoked while travelling on the tram.
- Tram parameters can be changed through the interactive (moveable) menu at any time.




## Installation Details

### Client (Local) or Single Player machine:
Make sure Icarus has been shutdown, 
Place all your mod files (*.pak) in the game mods folder located here:

(drive):\Program Files (x86)\Steam\steamapps\common\Icarus\Icarus\Content\Paks\mods

if the ...\mods directory does not exist, create it.

### Hosted Multiplayer or Dedicated Server:
Make sure Icarus has been shutdown, 
Place all your mod files (*.pak) in the dedicated server game mods folder typically located here:

(drive):\<IcarusServerFolder>\Icarus\Content\Paks\mods

NOTE - Replace (drive):\<IcarusServerFolder>\ with the applicable location you installed your Icarus Dedicated Server app.

if the ...\mods directory does not exist, create it.

Use the exact same mods on both server (or hosted PC) and all client machines connected or else run the risk of weird stuff happening.
Usually the server settings/mods will override anything running on the local client machine(s), but match the mods to stay out of trouble.
